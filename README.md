# 영어 학원 평가 도우미

PDF 정답지에서 정답과 배점을 추출해 OMR을 자동 채점하고, 통계·학생별 결과를 엑셀로 내려받는 Streamlit 웹서비스입니다. AI Agent로 성적 조회와 유사 문제 생성을 지원합니다.

## 평가 필수 정보

- 학번 및 이름: **미입력 — 제출 전 실제 정보 입력 필요**
- 배포 URL: **미입력 — 실제 배포 후 입력 필요**
- 서비스 유지 기한: 11월 11일 23:59

## 실행

Python 3.11 환경에서 다음을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

로컬에서는 `.env`에 `OPENAI_API_KEY`를 설정합니다. Streamlit 배포 환경에서는 Secrets에 같은 이름으로 설정합니다. 키 파일을 공유하거나 저장소에 올리지 마세요.

## 사용 방법

1. 홈에서 데이터 분석 페이지로 이동합니다.
2. 사이드바에서 영어 문제 PDF, 정답 PDF, OMR CSV를 업로드합니다.
3. 분석 시작을 누릅니다.
4. 전체 통계와 학생별 결과를 확인하고 엑셀 추출을 누릅니다.
5. 채팅에서 성적·통계를 질문하거나 최다 오답 문항의 유사 문제를 요청합니다.

OMR CSV는 `학생명`, `Q01`부터 `Q45`까지의 열이 필요합니다. 학생명은 비어 있거나 중복될 수 없습니다. 응답은 1~5이며 빈칸 또는 0은 미응답으로 오답 처리합니다. 텍스트가 추출되는 PDF를 사용하세요. 정답 PDF는 45문항, 총 100점인지 검증합니다.

파일을 변경하거나 재분석하면 이전 결과와 대화는 초기화됩니다. 같은 분석의 대화 세션에서는 이전 대화를 전달합니다. 새로고침 후 영구 보관은 하지 않습니다.

## 검사

샘플 PDF·CSV가 같은 폴더에 있을 때 다음을 실행합니다. 두 검사는 외부 API를 호출하지 않습니다.

```powershell
python -m unittest test_review -v
python test_ui.py
```

검수 내역과 아직 확인되지 않은 배포·실제 AI 응답 항목은 `검수보고서.md`를 참고하세요.
